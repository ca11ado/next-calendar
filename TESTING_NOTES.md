### 3. Расчёт высоты при 100%

**Формула:**

```
availableHeight = window.innerHeight - HEADER_HEIGHT - FOOTER_HEIGHT
totalRows = сумма всех year.rowCount (зависит от событий)
baseRowHeight = availableHeight / totalRows
actualRowHeight = baseRowHeight × (zoomScale / 100)
totalHeight = totalRows × actualRowHeight
```

**При 100%:**

- actualRowHeight = baseRowHeight
- totalHeight = availableHeight
- Скролл НЕ нужен

**При 150%:**

- actualRowHeight = baseRowHeight × 1.5
- totalHeight = availableHeight × 1.5
- Скролл нужен (totalHeight > availableHeight)

**Минимальная высота ряда:** 20px (MIN_ROW_HEIGHT)

- Если baseRowHeight < 20px даже при 100%, будет скролл

### 4. События переходящие на следующий год

Если событие начинается в одном году и заканчивается в другом:

- В году начала: событие идёт до конца года (31 декабря)
- В году окончания: новое событие с начала года (1 января)

**Пример в тестовых данных:**

- Школа: 1996-2007 (появляется в каждом году с 1996 по 2007)
- Университет: 2007-2012 (появляется в каждом году с 2007 по 2012)

**Что проверять:**

- Длинные события корректно отображаются в каждом году
- Нет разрывов или перекрытий между годами

### 6. Экспорт/Импорт структура JSON

**Структура экспортированного файла:**

```json
{
  "version": "1.0",
  "exportDate": "2025-01-15T10:30:00.000Z",
  "events": [
    {
      "id": "uuid-here",
      "title": "Название",
      "startDate": "2020-01-01T00:00:00.000Z",
      "endDate": "2020-12-31T00:00:00.000Z",
      "category": "work",
      "description": "Описание"
    },
    {
      "id": "uuid-here-2",
      "title": "Текущее событие",
      "startDate": "2019-10-01T00:00:00.000Z",
      "endDate": null,
      "category": "work",
      "description": "Текущая работа"
    }
  ]
}
```

**Критично:**

- Даты экспортируются как ISO строки
- При импорте преобразуются обратно в Date объекты
- null корректно обрабатывается для текущих событий

### 8. Анимации и transitions

**Компоненты с transitions:**

- Timeline container: `transition-all duration-300`
- Timeline inner: `transition-all duration-300`
- YearRow: `transition-all duration-300`
- EventBar: `transition-all duration-300`

**Что проверять:**

- При изменении ZoomScale: плавное изменение высоты (300ms)
- При hover на EventBar: плавное появление тени
- Нет рывков или мерцания

### 9. Валидация форм: правила

1. **Название обязательно:** `if (!title.trim())`
2. **Дата начала обязательна:** `if (!startDate)`
3. **Дата окончания обязательна если !isCurrent:** `if (!isCurrent && !endDate)`
4. **Логика дат:** `if (startDate > endDate)`

### 10. Производительность

**Оптимизации в коде:**

- `useMemo` для `yearsData` в Timeline (пересчёт только при изменении events/zoomScale/viewportHeight)
- `useCallback` для всех обработчиков событий в page.tsx
- `debounce` для resize (150ms)
- CSS `transition-all` использует GPU ускорение

**Что проверять:**

- Нет лагов при изменении масштаба
- Нет лагов при resize окна
- Hover на события мгновенный

## Известные ограничения

1. **Мобильные устройства:** Не оптимизировано для маленьких экранов (<768px)
2. **Очень много событий:** Нет виртуализации, может быть медленно при >500 событиях
3. **Браузеры:** Тестировалось на Chrome/Firefox, Safari не проверялся
4. **LocalStorage лимит:** ~5-10MB, достаточно для ~1000 событий
