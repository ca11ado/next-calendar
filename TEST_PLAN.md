# Тест-план для ручного тестирования календаря жизни

## Запуск приложения

```bash
npm run dev
```

Откройте http://localhost:3000 в браузере.

## 1. Тестирование основных функций (CRUD)

### 1.1 Добавление события

- [ ] Нажать кнопку "+ Добавить событие"
- [ ] Заполнить форму:
  - Название: "Тестовое событие"
  - Категория: Работа
  - Дата начала: 2020-01-01
  - Дата окончания: 2020-12-31
  - Описание: "Тест"
- [ ] Нажать "Добавить"
- [ ] Проверить: событие появилось на таймлайне в 2020 году
- [ ] Проверить: цвет соответствует категории "Работа" (зелёный)

### 1.2 Просмотр деталей события

- [ ] Кликнуть на любое событие на таймлайне
- [ ] Проверить: открылась модалка с деталями
- [ ] Проверить: отображаются все поля (название, категория, даты, описание)
- [ ] Проверить: кнопки "Закрыть", "Редактировать", "Удалить" доступны

### 1.3 Редактирование события

- [ ] В модалке деталей нажать "Редактировать"
- [ ] Изменить название на "Обновлённое событие"
- [ ] Нажать "Сохранить"
- [ ] Проверить: модалка закрылась
- [ ] Проверить: событие обновилось на таймлайне
- [ ] Кликнуть на событие снова
- [ ] Проверить: отображается новое название

### 1.4 Удаление события

- [ ] В модалке деталей нажать "Удалить"
- [ ] Проверить: появилось диалоговое окно подтверждения
- [ ] Нажать "OK"
- [ ] Проверить: событие удалено с таймлайна
- [ ] Проверить: модалка закрылась

### 1.5 Текущее событие (без даты окончания)

- [ ] Создать событие с галочкой "Текущее событие"
- [ ] Проверить: событие отображается от даты начала до текущего года
- [ ] Проверить: в деталях показано "Настоящее время" вместо даты окончания

## 2. Тестирование масштабирования (9 комбинаций)

### Единицы времени: Дни

- [ ] Переключить на "Дни"

- [ ] Масштаб 150%: проверить наличие вертикального скролла
- [ ] Масштаб 200%: проверить наличие вертикального скролла

### Единицы времени: Недели (по умолчанию)

- [ ] Переключить на "Недели"
- [ ] Масштаб 100%: проверить отсутствие скролла
- [ ] Масштаб 150%: проверить наличие вертикального скролла
- [ ] Масштаб 200%: проверить наличие вертикального скролла

### Единицы времени: Месяцы

- [ ] Переключить на "Месяцы"
- [ ] Масштаб 100%: проверить отсутствие скролла
- [ ] Масштаб 150%: проверить наличие вертикального скролла
- [ ] Масштаб 200%: проверить наличие вертикального скролла

### Критерии проверки масштабирования

- [ ] Переключение между режимами плавное (transition 300ms)
- [ ] События масштабируются вертикально при изменении ZoomScale
- [ ] События НЕ меняют вертикальный размер при изменении TimeUnit
- [ ] Годы всегда занимают целое число рядов
- [ ] Нет визуальных артефактов или мерцания

## 10. Алгоритм размещения событий

### Перекрывающиеся события

- [ ] Найти год с несколькими событиями в разных рядах
- [ ] Проверить: события НЕ перекрываются визуально
- [ ] Проверить: каждый ряд имеет одинаковую высоту

### Один год = целое число рядов

- [ ] Проверить несколько годов
- [ ] Убедиться: каждый год занимает РОВНО свои ряды (не переходит на другой год)

### События переходящие на следующий год

- [ ] Создать событие с датами 2023-10-01 до 2024-02-01
- [ ] Проверить: в 2023 событие идёт до конца года
- [ ] Проверить: в 2024 событие начинается с начала года
