## Обзор проекта

Создание приложения на Next.js 16 для визуализации периодов жизни (учёба, работа, поездки) на одном экране. Календарь показывает всю жизнь с 25.03.1989 на протяжении 70 лет, чтобы видеть масштаб событий относительно всей жизни.

## Ключевая особенность визуализации

**Вертикальное размещение по годам с адаптивным масштабированием**:

- Каждый год занимает отдельную горизонтальную полосу (или несколько полос при наличии перекрывающихся событий)
- Годы размещаются вертикально друг под другом
- При масштабе 100% (по умолчанию): все 70 лет жизни видны на одном экране без скроллинга
- При увеличении масштаба (150%, 200%): появляется вертикальный скролл, события становятся крупнее
- События внутри года размещаются горизонтально по временной шкале года
- Высота каждого года адаптивно вычисляется на основе доступного пространства и масштаба

## Ключевые требования

### Визуализация

- **Тип отображения**: Цветные горизонтальные полосы с деталями при наведении/клике
- **Временная шкала**: 25.03.1989 + 70 лет
- **КРИТИЧНО**: Разные годы не могут быть на одной строке - одному году соответствует целое число строк (≥1) во ВСЕХ режимах масштабирования
- **Перекрывающиеся события**: Автоматическое размещение в несколько горизонтальных рядов ВНУТРИ года

### Масштабирование (два независимых типа)

**По умолчанию**: Календарь занимает всё свободное место экрана БЕЗ прокрутки

**Тип 1 - Размер календаря (ZoomScale)**:

- Три уровня: 100% (по умолчанию), 150%, 200%
- 100%: всё видно на экране БЕЗ скролла
- 150% и 200%: появляется вертикальный скролл, события крупнее
- Изменяет вертикальный размер событий

**Тип 2 - Единицы времени (TimeUnit)**:

- Три режима: Дни, Недели (по умолчанию), Месяцы
- Меняет горизонтальную детализацию временной шкалы внутри года
- НЕ влияет на вертикальный размер и количество рядов
- Независим от ZoomScale

### Функциональность

- UI для добавления, редактирования и удаления событий
- Хранение данных в localStorage
- **Экспорт событий в JSON файл**
- **Импорт событий из JSON файла**
- Тестовые события для демонстрации
- Категории событий: учёба, работа, путешествия, личное, другое

## Этап 12: Исправление критических багов (после первого запуска)

### Обнаруженные проблемы при тестировании:

#### Проблема 1: При 100% масштабе не видно всех годов (КРИТИЧНО)

- **Описание**: При масштабе 100% виден только диапазон до ~2027 года, но должно быть видно все 70 лет (1989-2059) БЕЗ скролла
- **Ожидаемое поведение**: Весь временной диапазон виден на экране без вертикального скролла
- **Возможные причины**:
  - Неправильный расчет availableHeight (не учитывается footer)
  - HEADER_HEIGHT указан неправильно (должен включать все отступы)
  - MIN_ROW_HEIGHT слишком большой
- **Файлы для проверки**:
  - `src/lib/constants.ts` - HEADER_HEIGHT
  - `src/components/calendar/Timeline.tsx` - расчет availableHeight
  - `src/app/page.tsx` - структура с footer

#### Проблема 2: Года обрезаны (КРИТИЧНО)

- **Описание**: Текст годов (1989, 1990 и т.д.) визуально обрезан или не полностью отображается
- **Ожидаемое поведение**: Метки годов полностью видны и читаемы
- **Возможные причины**:
  - overflow: hidden на YearRow
  - Недостаточная ширина колонки с годом
- **Файлы для проверки**:
  - `src/components/calendar/YearRow.tsx` - стили колонки года

#### Проблема 3: Нет визуализации временной сетки (УЛУЧШЕНИЕ)

- **Описание**: При режиме "Недели" не видно границ недель, непонятен масштаб времени
- **Ожидаемое поведение**: Видны вертикальные линии-разделители для недель (52 линии на год)
- **Решение**: Добавить компонент TimeGrid для отображения временной сетки
- **Файлы для изменения**:
  - Создать `src/components/calendar/TimeGrid.tsx`
  - Обновить `src/components/calendar/YearRow.tsx` - добавить сетку в фон

#### Проблема 4: Длинные события не дублируются на годы (КРИТИЧНО)

- **Описание**: События, которые длятся несколько лет (например, Школа 1996-2007), отображаются ТОЛЬКО в году начала, но НЕ продолжаются на следующих годах
- **Ожидаемое поведение**:
  - Школа (1996-2007) должна показываться в КАЖДОМ году: 1996, 1997, 1998, ..., 2007
  - В 1996: от даты начала до 31 декабря
  - В 1997-2006: с 1 января по 31 декабря (весь год)
  - В 2007: с 1 января до даты окончания
- **Корень проблемы**: `layoutEngine.ts` НЕ дублирует события на несколько годов
- **Файлы для исправления**:
  - `src/lib/utils/layoutEngine.ts` - функция `generateYearsLayout` должна создавать отдельное событие для каждого года
